# 🎥 피피비디오OCR파인더 (Pipi Video OCR Finder)

robo 님만을 위한 안드로이드 전담 동영상 한글 자막/글자 검색기 앱입니다.

## ✨ 주요 기능
- **구글 ML Kit 온디바이스 AI 탑재**: 인터넷/데이터 필요 없는 100% 오프라인 고정밀 한글 인식
- **10초 이내 고속 스캔**: 영상 전체를 다 보지 않고 시작 후 10초 이내 핵심 구간 집중 분석
- **타임스탬프 원클릭 재생**: 찾은 글자를 누르면 해당 시간대로 즉시 점프 재생

## 📦 APK 다운로드
상단 [Releases](../../releases) 탭에서 최신 `app-debug.apk`를 다운로드하여 안드로이드 스마트폰에 설치할 수 있습니다.
